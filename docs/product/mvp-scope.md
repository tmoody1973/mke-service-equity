# MVP Scope

## Included

- Milwaukee County coverage
- City of Milwaukee analytical focus
- Census tract Equity Baseline
- Food Access Need
- Food Equity Priority
- Atlas
- Search
- Tract Profile
- verified food resources
- accessibility indicators
- Compare Areas
- Opportunity Explorer
- methodology
- data source registry
- quality states
- CSV export
- shareable state
- responsive experience
- accessibility
- production QA

## Deferred

- transit travel-time routing if it becomes a release blocker
- advanced public-land opportunity analysis if local asset data is not sufficiently reliable
- vector-tile infrastructure until GeoJSON/data volume justifies it
- automated partner-data sync when structured partner feeds are unavailable

## Not MVP

See the PRD exclusions. The build must not expand scope without a specification change.
